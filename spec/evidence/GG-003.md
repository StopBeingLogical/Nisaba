## The identifiers that actually arrive

`storeShortLabel` (`handlers/handlers.go`) maps whatever a provider stored in
`best_current_store` / `price_history.store`. Under ITAD that is
`shop.name` — and the exact set is knowable rather than guessable, so it was
fetched rather than assumed:

```bash
$ curl -s "https://api.isthereanydeal.com/service/shops/v1?key=…" | …
34
2 | AllYouPlay… 4 | Blizzard  6 | Fanatical  16 | Epic Game Store  20 | GameBillet
24 | GamersGate  25 | Gamesload  26/27/28/29 | GamesPlanet UK/FR/DE/US  35 | GOG
36 | GreenManGaming  37 | Humble Store  42 | IndieGala Store  48 | Microsoft Store
49 | Newegg  61 | Steam  62 | Ubisoft Store  64 | WinGameStore  72 | ZOOM Platform
(+ 13 more: DLGamer, Dreamgame, EA Store, FireFlower, Fortuna Digital, JoyBuggy,
MacGameStore, Muve, PlanetPlay, PlayerLand, Playsum, Zapagames)
```

The live copy's post-cutover data used 20 of those 34 (see `GG-002`), so the
mappings were extended for the ones where ITAD's canonical name is not the
label worth showing, and the rest deliberately fall through:

| Stored value | Label |
|---|---|
| `Humble Store` | Humble |
| `Epic Game Store` | Epic |
| `GreenManGaming` | Green Man Gaming |
| `EA Store` | EA Store |
| `Microsoft Store` | Microsoft Store |
| `Ubisoft Store` | Ubisoft Store |
| `Blizzard` | Battle.net |
| `Steam`, `GOG`, `Fanatical` | unchanged from the existing switch |
| `AllYouPlay`, `GameBillet`, `Playsum`, `WinGameStore`, `Nuuvem`, … | raw value |

**The fallback is the point.** The `default` arm returns `s` unchanged — the raw
stored identifier — so an unmapped shop shows `AllYouPlay`, never blank. Only
the empty string returns `—`. This is what `ACCEPTANCE.md` asks for: "an unmapped
identifier degrades to the raw value rather than blank".

The `gg.deals/retail` / `gg.deals/keyshop` mapping is left in place but is now
unreachable for new data: after the scorched-earth cutover, no writer produces
category-level store values (`GG-005` confines GG.deals to its own columns).
