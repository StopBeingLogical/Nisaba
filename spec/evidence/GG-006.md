## What changed

| File | Change |
|---|---|
| `templates/wishlist_detail.html` | callout in the Pricing card: existence of the lower price, its amount, and a link to the game's GG.deals page |
| `templates/wishlist_grid_partial.html` | compact "Cheaper on GG.deals" marker under the current price |
| `templates/wishlist_cards_partial.html` | same marker in the card caption |

Each is a single guard:

```gotemplate
{{ if and .GGDealsPrice.Valid .BestCurrentPrice.Valid (lt .GGDealsPrice.Float64 .BestCurrentPrice.Float64) }}
```

Both sides must exist before anything renders, so an entry with no ITAD price,
no GG.deals listing, or a GG.deals price that is not lower shows nothing at all.

**The grid and card views deliberately render a span, not a link.** Both sit
inside an `<a>` wrapping the whole row, and a nested anchor is invalid HTML that
browsers unnest unpredictably. The clickable link lives on the detail page,
which is one click from any row in those views.
